What PCA can't see

Nonlinear autoencoders, hidden structure, and the limits of reconstruction loss.
Lucia Domenichelli · 12 November 2026 · about 5 min

If a model can reconstruct its input well, has it learned the things we care about? It is tempting to say yes. But copying an observation and finding the hidden factors behind it are different goals.

This is a short, visual reading note on Mendes et al. (2026). Start with a curve, then a bottleneck, then two ways of judging what a model has learned.

01 / the blind spot 02 / the bottleneck 03 / two scorecards

01 / the blind spotConnected does not always mean correlated

Principal component analysis (PCA) finds linear directions along which data vary the most. Its map of the data is the covariance matrix: a summary of variances and pairwise linear relationships.

Now imagine y = x², with x sampled symmetrically around zero. Positive and negative values of x give the same y. Their contributions to covariance cancel, so the linear correlation is zero. Yet knowing x tells us y exactly.

This curve alone does not make a direction invisible to PCA: PCA still sees the variance along each axis. The paper goes further. It constructs noisy, high-dimensional data with two hidden directions. One leaves a covariance signal; the other is normalized so that its extra variance disappears. The two latent factors remain dependent beyond covariance. [Paper, §1]

Higher-order structure means relationships that need more than pairs of quantities multiplied together to become visible. A nonlinear feature such as x² gives us a first intuition for how to look for them.

02 / the bottleneckLearning by trying to reconstruct

An autoencoder sends an input through an encoder to make a compact code, then through a decoder to reconstruct the input. The code is its representation. Training adjusts the model to reduce the difference between the original and the reconstruction.

With linear maps and squared reconstruction error, an optimal undercomplete autoencoder recovers the same principal subspace as PCA. Nonlinear activations let the training objective respond to richer statistical relationships.

Here, a single hidden unit with a suitable nonlinearity learns a direction correlated with both hidden directions, including the one PCA misses. This is partial recovery, not perfect disentanglement. Which nonlinearity works depends on the data. [Paper, §4]

03 / two scorecardsA better copy, or a more useful representation?

Test reconstruction loss asks: “How accurately can the model rebuild inputs it did not train on?” A downstream task asks whether what it learned helps with another goal, such as predicting a label. Both use new data, but they measure different things.

The test set is doing its job: it measures reconstruction on fresh samples. The mismatch comes from using that score to answer a different question about learned structure. A useful evaluation must match what we want to do with the representation.

My takeaway: a low reconstruction loss tells us how well a model copies. To learn what it has understood, we need to ask what its representation makes possible.

This deliberately simplified model makes the distinction analyzable. It does not establish that every nonlinear autoencoder outperforms PCA.

The paper behind this note

Vicente Conde Mendes, Lorenzo Bardone, Cédric Koller, Jorge Medina Moreira, Vittorio Erba, Emanuele Troiani and Lenka Zdeborová. A solvable high-dimensional model where nonlinear autoencoders learn structure invisible to PCA while test loss misaligns with generalization. ICML 2026.
