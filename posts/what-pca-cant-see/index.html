01 / THE BLIND SPOT

Uncorrelated.
Still connected.

PCA looks for directions with the most variance. But covariance only captures part of the picture. Here, the coordinates have equal variance and zero covariance: PCA has no preferred direction, while the curve is easy to see.

Try the nonlinear lens. We supply the feature x², which exposes the relationship. This is a toy illustration, not a trained model; squaring x also loses its sign.

How does this connect to the paper?

The paper hides two directions in high-dimensional noise. One appears in covariance; the other is whitened so its extra variance disappears. Their latent factors remain dependent beyond covariance. Our two-dimensional sketch illustrates the blind spot, not that full model. Keeping both PCA components would still retain this entire toy dataset. Read §1 ↗

A good copy is only one kind of success.

Reconstruction error tells us how much of the input was reproduced. It doesn’t tell us whether the code captured a factor we need for another task.

What this experiment is doing

This is a fixed linear encoder and decoder: it keeps a chosen number of low-frequency image components using a discrete cosine transform. No network is trained here. It illustrates compression and reconstruction; the paper studies a different, learned nonlinear autoencoder.

The idea to take with you

Learning to reconstruct
isn’t the same as learning
what matters.

The test set can be perfectly valid while the metric answers the wrong question. Choose an evaluation that reflects what you want the representation to do.
Behind the experiments

A small model.
A useful distinction.

Under the paper’s conditions, even a single hidden unit with a suitable nonlinearity can learn a direction correlated with both planted directions. This is partial recovery, not perfect disentanglement, and it is not a universal claim that nonlinear models beat PCA.
