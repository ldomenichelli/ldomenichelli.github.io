Strange Attractors

Three deterministic systems, one small RK4 solver, and trajectories that never quite repeat. Every line you see below was integrated and drawn by the downloadable Fortran program.

enter the phase space ↓ download .f90

the experiment

Deterministic equations, unpredictable paths

A strange attractor is not a random cloud. It is the long-term geometry traced by a nonlinear dynamical system. Nearby initial states separate rapidly, yet the orbit remains confined to a recognisable shape: chaos with structure.

under the hood

The curve is the program’s output

The source uses 64-bit reals and a fourth-order Runge–Kutta step. It discards an initial transient, keeps 30,000 states, projects two coordinates, and writes each plot directly as SVG. There is no browser-side numerical solver or plotting dependency.

subroutine rk4_step(system_id, state, dt)
  integer, intent(in) :: system_id
  real(dp), intent(inout) :: state(3)
  real(dp), intent(in) :: dt
  real(dp) :: k1(3), k2(3), k3(3), k4(3)

  call velocity(system_id, state,                 k1)
  call velocity(system_id, state + 0.5_dp*dt*k1, k2)
  call velocity(system_id, state + 0.5_dp*dt*k2, k3)
  call velocity(system_id, state + dt*k3,        k4)

  state = state + dt*(k1 + 2*k2 + 2*k3 + k4)/6
end subroutine rk4_step

subroutine velocity(system_id, state, rate)
  integer, intent(in) :: system_id
  real(dp), intent(in) :: state(3)
  real(dp), intent(out) :: rate(3)
  real(dp) :: x, y, z

  x = state(1); y = state(2); z = state(3)

  select case (system_id)
  case (1) ! Lorenz
    rate = [10*(y - x), x*(28 - z) - y, &
            x*y - (8.0_dp/3.0_dp)*z]
  case (2) ! Rossler
    rate = [-y - z, x + 0.2_dp*y, &
            0.2_dp + z*(x - 5.7_dp)]
  case (3) ! Thomas
    rate = [sin(y) - 0.208186_dp*x, &
            sin(z) - 0.208186_dp*y, &
            sin(x) - 0.208186_dp*z]
  end select
end subroutine velocity

reproduce it

Compile, run, inspect

A modern Fortran compiler is the only requirement. Running the executable writes all three SVG files into the current directory.

$ gfortran -std=f2008 -O2 strange-attractors.f90 -o strange-attractors
$ ./strange-attractors
Wrote lorenz.svg, rossler.svg, and thomas.svg
